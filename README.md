# Curso de Copilot Studio da DIO
Respositório utilizado para mostrar o aprendizado em Microsoft Copilot Studio do Curso da DIO

## O que aprendi?
Neste conteúdo fui apresentado ao Microsoft Copilot Studio e ao Power Apps, soluções criadas plea Microsoft utlizadas para a criação de agentes baseados em inteligência artificial e automatização de processos, respectivamente.

Fui introduzido ao conceitos de ambientes, conectores, soluções, entre diversos outros que serão necessários para a organização e estruturação desta etapa do curso da Suzano - Python Developer.

Neste desafio, aprendi a criar um Agente com base em um modelo pronto, neste caso, um modelo de Viagens. Também entendi a como criar um agente com base em uma descrição, descrição essa que é interpretada pelo Copilot para a criação de agentes no Copilot Studio. Também fui exposto ao aprendizado envolvendo a criação de um copliot em branco, útil para criar um Copilot próprio que não tenha um modelo pronto para se basear.
